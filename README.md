# owasp-website-issues

A repo to report issues with the OWASP Foundation public website and related specialized project websites.

Please use the website bug report issue form to include:

- a description of the concern
- the affected URL
- reproduction steps
- expected behavior or desired resolution
- screenshots, when available

Please use the feature enhancement request issue form to include:

- whether the request improves existing functionality or adds new functionality
- the area where the enhancement would be implemented
- the desired end state or functionality
- optional test step suggestions to confirm the enhancement works correctly
